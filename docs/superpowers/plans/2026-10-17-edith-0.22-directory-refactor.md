# EDITH 0.22 目录与包名重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在**不改变任何功能行为**的前提下，把 23 个 Gradle 模块重组为“两端 + 公共依赖 + 仪器”的顶层结构，并把交付代码包名统一到 `com.sheen.rokid.*`。

**Architecture:** 纯机械迁移：`git mv` 移动模块与包目录，逐模块替换 `package`/`import`/完全限定名，同步 Gradle 路径、Manifest 组件名、proguard、AIDL、test runner 与文档路径。每个任务结束都必须全量编译 + 全量 JVM 测试通过；不新增、不删除、不改写任何业务逻辑。

**Tech Stack:** Gradle Kotlin DSL、Kotlin/Java、Android（compileSdk 35）、PowerShell、adb。

**Spec:** `docs/superpowers/specs/2026-10-17-edith-0.22-directory-refactor-design.md`

## Global Constraints

- 交付代码包名：`com.sheen.rokid.*`；探针/工具保留 `edith.*`；vendored `com.laya` 不变。
- 两端 `applicationId`：`com.sheen.rokid.phone` / `com.sheen.rokid.glasses`。
- 顶层只允许：`phone-app/`、`glasses-app/`、`common/`、`tools/`、`third_party/`、`docs/`。
- 不改 Gradle 模块边界；不新增/合并模块。
- 运行期协议逐字节不变：`edith.START`/`PAUSE`/`RESUME`/`STOP`、`edith.CONFIRM_*`、`edith.DEBUG_*`、`edith.phone.SHOW_CONFIRMATION`、`edith.session`、`edith.cxr.*`、唤醒词 `edith`、`/sdcard/EDITH/skills`。
- 探针包名不变：`edith.phone.a11yprobe`、`edith.glasses.probe`、`edith.glasses.coexistence`、`edith.probe.*`、`edith.survey.shizukuprobe`。
- 只允许 `git mv`；禁止复制后删除。
- 每个任务结束：`assembleDebug`（两端）+ 全量 JVM 测试通过，才允许提交。
- 基线：0.21 的 **310 套件 / 2671 tests / 0 failures / 0 errors / 0 skipped**；本次以实际 XML 聚合为准，数量差异必须解释。
- 不 push、不打 tag；既有探针 WIP 只作为独立提交。
- 不重跑 F4/M2/AC-13/16，不修改任何验收判词。

## Review Focus

1. **反射/字符串类名断链**：Shizuku UserService（`EdithShellService` 由厂商进程按类名实例化）、Laya 宿主、R8 keep 规则。改名后必须 release 构建 + 设备 Shizuku 通道可用，不能只看编译通过。
2. **两端目标常量不同步**：`CxrGlassesTarget` 硬编码眼镜包名/Activity 名；改端必须同时更新 `transport-rokid` 测试与 `Cxr*Test`，并在设备上验证提示上屏。
3. **设备授权组件名失效**：无障碍服务、通知监听、Shizuku 授权的组件名随包名变化；重装后必须重新授权，且写 `enabled_accessibility_services` 前保留既有服务。
4. **`.gitignore` 吞掉 `audio` 包**：Windows 大小写不敏感，`Audio/` 规则曾让 16 个引擎文件不入库（D45）；包改名后必须用 `git check-ignore` 验证新 `audio` 包未被忽略。
5. **测试假绿**：包移动后漏跑模块或 JUnit XML 聚合遗漏都会显示“全绿”；每次按 XML 聚合套件/用例数并与基线对照。

## 机械操作约定

- **包重写脚本**：统一使用 Task 6 Step 2 的 PowerShell 模式（`[System.IO.File]` 读/写、只写回变化文件、`<old>.` 前缀与 `package <old>` 行一起替换）。后续任务只替换 `$map`。
- **保护字面量**：Task 9 执行前把 `edith.glasses.probe`、`edith.glasses.coexistence` 替换为占位符 `__PROBE_G__`；Task 10 执行前把 `edith.phone.a11yprobe` 替换为 `__PROBE_A__`；任务结束立即还原。Intent action（`edith.START` 等）不含 `.` 后的模块名，不会被前缀替换命中。
- **建父目录**：每次 `git mv` 前先 `New-Item -ItemType Directory -Force <目标父目录> | Out-Null`。
- **提交**：除 Task 1 需要显式添加新文件外，其余任务统一 `git add -u`，避免把未跟踪的 `tools/shizuku-shell-probe/` 与两个 `gradle.lockfile` 误带入。
