# EDITH 0.3 Phase 4A — 24 工具面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把生产工具面从 6 个接到 24 个默认工具（atomic 18 + umbrella 4 + 交付 2），统一风险级与描述契约，完成提示词迁移、架构测试与单工具延迟遥测。

**Architecture:** 新增 `ToolSurface` 复合 `ActionExecutor`，有序持有 atomic backend 与 `ToolCatalog`，单一 `Capability.Actions` provider；`ToolCatalog` 改为稳定广告；插件仍贡献 `notify_user`/`load_skill`，最终 registry 为 24。提示词继续由 `PromptCatalog` 资源化，硬编码迁入 base/loop/pinned 资源；`AgentLoop` 只通过构造参数接收文本。

**Tech Stack:** Kotlin / Gradle / JUnit 4 / Android a11y + Shizuku；纯 JVM 优先。

**Spec:** [2026-10-22-edith-0.3-phase-4-tool-face-and-permission-design.md](../../superpowers/specs/2026-10-22-edith-0.3-phase-4-tool-face-and-permission-design.md)

## Global Constraints

- 不重做 Phase 3；不改 0.21/0.25/0.26/Phase 3 旧判词；`Partial`/`NotMeasured` 不读成通过。
- 不 push / 不 tag / 不 merge；提交信息按 `feat(...)`/`docs(...)`。
- 24 个默认工具、0 同名冲突、组合根只有一个 `Capability.Actions` provider；`propose_hint` 只在 `PROACTIVE_HINT` 回合广告。
- 工具集按 App 版本 + 会话开始能力固定；掉线时保留广告并返回 `CHANNEL_UNAVAILABLE`，不静默删工具。
- `dial` 只允许 `ToolCatalog.DialTool`；`IntentActionExecutor.dial` 不得广告。
- 风险级：atomic `tap`/`long_press`/`input_text` 统一 L1；`set_brightness` L2；`clear_data`/`uninstall` L3；`disable_app`/`set_permission` L4。
- 无新依赖、无 CXR wire 变化、无新权限；日志/证据零正文，只记计数/形状/哈希。
- 全量 JVM gate（八模块，同一命令，`--rerun-tasks`；计数只从 JUnit XML）：
  `.\gradlew :common:contracts:plugin-api:test :phone-app:assistant:host-runtime:test :phone-app:assistant:device-control:test :phone-app:assistant:agent-runtime:test :phone-app:assistant:model-runtime:test :common:presentation:output-runtime:test :phone-app:plugins:plugin-smart-helper:test :phone-app:app:testDebugUnitTest --rerun-tasks`
- 设备操作不在本计划默认执行；需要业主授权后另行执行；`adb -s 2696813b`、禁用 `gradlew installDebug`、UI 只用 `edith.phone.a11yprobe`。

## Review Focus

1. **同名工具/第二 provider**：atomic 与 umbrella 同时广告、`dial` 双声明、`ExecutionRouter` 被误接成第二个 provider —— 用户会看到重复工具或错误 risk；由 Task A3/A4 的重复名与 provider 测试钉住。
2. **掉线时工具消失**：a11y/Shizuku/通话权限掉线后工具从 schema 消失，破坏缓存前缀与模型判断；由 Task A3/A4 的稳定广告/`CHANNEL_UNAVAILABLE` 测试钉住。
3. **描述与用户标签混用**：长模型描述被眼镜工具行当用户标签；由 Task A1/A5 的 `ToolLabelMap` 与 description 分离测试钉住。
4. **atomic 与 umbrella 语义混淆**：`read_screen` index 与 `device` #ref 是两套命名空间；由 Task A5 的 ToolContract/ToolRouting 测试钉住。
5. **提示词硬编码回归**：迁移后仍残留 Kotlin 提示词或 gate 文案被改写；由 Task A6–A8 的 golden/字面/扫描测试钉住。
