# EDITH 0.24 官方助手交互对齐实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` (recommended) or `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The approved spec travels with this plan and wins on any conflict.

**Goal:** 把 EDITH 的眼镜会话交互做成官方「乐奇助手」的可观察行为：常驻会话、唤醒即弹出/息屏点亮、10 s 自动关闭、持续对话、120 s 钉住行为、官方按键/提示/BACK、ASR 逐字/答案流式/Markdown/PAG/GIF。

**Architecture:** 手机会话仍是唯一 session owner；点一次「开始」后 CXR/采音/KWS 常驻。眼镜端从单一 Activity 改为 **前台服务 + `TYPE_APPLICATION_OVERLAY` 悬浮面板**；Activity 只做 CXR 入口/悬浮窗授权跳板。面板状态机、缓存与渲染从 Activity 抽到可测试的 controller/view。线缆只做加法式命令（`wireVersion=1`，旧解码器 null 安全失败）；旧 `SHOW/SAID/BUSY` 保留为 final 文本与降级路径。S1 先做设备 spike，未通过即停。

**Tech Stack:** Kotlin / Android View（眼镜）/ Jetpack Compose（仅手机既有页面）/ CXR-L 1.1.2 / libpag / Markwon / JUnit 4 / Android instrumentation / Gradle / adb。

**Spec:** `docs/superpowers/specs/2026-10-18-edith-0.24-official-interaction-parity-design.md`（业主 2026-10-18 批准）。决策 D157–D168 已登记在 `docs/project/DECISIONS.md`。官方依据：`D:\Project_new\rokid_glasses_UI\raw\rokid-wake-ui\cfr-src` 的 CFR Java 与 `docs/design/` 的 A/B 级材料。

**Current status:** 设计稿已批准；本计划待业主审阅并选择执行方式。**本计划批准前不写产品代码。**

- `wireVersion = 1`；新命令只做加法；旧解码器对未知命令返回 `null`；新眼镜对旧手机降级为“无逐字/无自动关闭”的旧行为。
- 常量（逐字）：`LISTEN_TIMEOUT_MILLIS = 10_000`、`PINNED_CLOSE_MILLIS = 120_000`、`TICKER_PIXELS_PER_FRAME = 1`、`TICKER_SKIP_FRAMES = 3`、`PAGE_FRACTION = 0.85`、`MAX_TEXT_CODEPOINTS = 400`、面板 380 px、PAG 55×45、ASR loading 26×13、思考图标 22×22、pin 图标 20×20、COMPLIANCE 12 px、ASR/用户 14 px、答案/思考/工具 16 px。

- 按键：DPAD 上/下在 `ACTION_DOWN` 处理并消费；ENTER/BACK 在 `ACTION_UP` 处理并消费；左/右不消费。pin 单向，不取消；pin 不停止 ticker。
- 10 s 计时只属于聆听态；任何 ASR 消息取消；思考/播报/工具期间不设计时；status 5 后新的 status 1 再开始。

- 不新增上传授权（D53 不变）；日志/证据只记计数、id、字符数、偏移、状态、哈希，不记正文；截图只含合成文本。
- 手机侧人工操作一律 `edith.phone.a11yprobe`（D95）；禁用 `adb shell input tap/text/swipe`。眼镜按键注入只作按键链证据，不作物理手感证据。
