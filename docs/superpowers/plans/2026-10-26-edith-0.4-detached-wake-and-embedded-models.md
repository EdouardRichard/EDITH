# EDITH 0.4 脱离眼镜唤醒、上下文输入与模型内置实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 EDITH 0.4 的唤醒词路线可在无眼镜、锁屏状态下用手机麦克风运行（主动辅助有效禁用），在唤醒路线上下文记录页提供文字与语音 ASR 输入，并把全部端侧模型内置进 APK、首启自动 provisioning，release 不再需要手工部署。

**Architecture:** 不新建第二条唤醒路线：手机麦克风与 CXR 麦克风共用 `PcmFramer`→`AudioIngressLoop`→KWS/`SpeechPipeline`，只替换采音源；脱离模式新增本地 scene readiness、手机 `HintDevice`（ack-only）与 `isPanelVisible=true`，不伪造 CXR 协议。文字消息走加法式 `UserAction.Action.Typed`，复用 `handleHelp` 的 WAKE 回合尾部但不复用其双路由 reset/cooldown。模型通过 app 模块 Gradle 任务校验后打进 `assets/models/**`，首启用 `BundledModelProvisioner` materialize 到现有运行目录，`ModelReadiness` 门禁覆盖组合根创建与会话启动。

**Tech Stack:** Kotlin 2.4 / Android Gradle Plugin（Compose UI、AudioRecord、ForegroundService）、sherpa-onnx（KWS/VAD/ASR）、Gradle Kotlin DSL、kotlinx.serialization JSON（App 侧）、PowerShell 脚本（构建/设备证据）。

**Spec:** `docs/superpowers/specs/2026-10-26-edith-0.4-detached-wake-and-embedded-models-design.md`

## Review Focus

- **文字消息落在 WAKE 回合忙/Idle 未结算/有排队句/确认挂起时**：必须拒绝且不取消既有回合、不撤回确认；用户输入保留。
- **手机显示设备的 ack**：memory-ack 的 `recordAsAnswer=false` emit 不得覆盖答案行；没有可见答案时不得谎报 `Displayed`；插件只在 `Displayed` 后结算。
- **脱离模式无眼镜启动**：不得依赖 `linkReady`/`liveOutput()`；迟到 `onSceneReady` 不得把本地会话误认为眼镜就绪。
- **锁屏唤醒**：`PARTIAL_WAKE_LOCK` 在 stop/pause/异常路径必须释放；FGS 类型必须与模式匹配；MIUI 杀掉时如实报错。
- **模型 provisioning 边界**：缺文件/错 SHA/中断/磁盘不足/APK 更新；不得留半 active bundle；非 READY 时启动必须在 `beforeStart` 前被拒。
- **听写与唤醒并发**：听写期间 KWS 不误触发、文本不进插件、CXR transport 不重启、单一采音所有者。
- **眼镜模式回归**：`glassesDetached=false` 时 CXR/面板/输出路径逐字节等价（JVM 现有测试 + 设备冒烟）。
