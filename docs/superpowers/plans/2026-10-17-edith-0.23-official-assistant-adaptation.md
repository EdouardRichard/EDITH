## Review Focus

以下五类输入/失败模式在规格里没有逐条写测试，但最可能伤到使用者；每行都在对应任务里补一条测试钉住：

1. **旧眼镜 APK + 新 STOP 命令**：旧解码器必须返回 null 而不是抛异常；新手机收到重复 STOP 必须幂等（Task 12/13）。
2. **emoji / 代理对 / 超长文本**：记忆缩略不能拆 surrogate；眼镜用户行 4 行截断不能抛异常（Task 4/6）。
3. **ticker 边界**：内容比窗口短、恰好等于窗口、已到底时不应启动或越界；用户翻页/钉住后不得继续动（Task 10/11）。
4. **语音朗读开关在唤醒时关闭/运行中切换**：关闭时短提示音不响；打开后第一次唤醒只响一次，800 ms 内不重复（Task 16）。
5. **无会话 / 过期代际 / 重复的 STOP**：不能取消别的会话，不能抛到 SDK 回调线程；无会话时 BACK 走退出（Task 13/14/15）。
