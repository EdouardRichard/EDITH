# EDITH 0.25 Agent 能力演进实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 EDITH 在「手机已解锁 + 亮屏」前提下，用 6 个薄工具完成跨 App 多步任务；模型能看见工具历史与截图；Loop/上下文不卡死、不爆窗口；以 7 条语料验收。

**Architecture:** 新增纯 JVM 的 `device-control` 内核（观察/ref/revision/diff/settle/动作/envelope），`app` 里的 `EdithAccessibilityService` 与 Shizuku 只做适配器；`agent-runtime` 增加 Loop 保护、并发执行器与 envelope 投影；`model-runtime` 补齐 Responses/Chat Completions 的工具历史与图片；`plugin-smart-helper` 负责提示词、store 与佩戴者 UX。

**Tech Stack:** Kotlin/JVM 17、Android（compileSdk 35 / targetSdk 33 / minSdk 28）、Gradle、kotlinx.serialization、JUnit5/kotlin.test、MockWebServer、Shizuku、DeepSeek `deepseek-flash`。

**Spec:** [docs/superpowers/specs/2026-10-19-edith-0.25-agent-evolution-design.md](../specs/2026-10-19-edith-0.25-agent-evolution-design.md)

## Global Constraints

- 版本 0.25；锁屏/息屏解锁**不做**（D7），本版只做任务期间亮屏锁，不唤醒息屏设备。
- 只做 TEXT+IMAGE；模型 `deepseek-flash`；**Responses 权威**，Chat Completions 兼容；AUDIO 不做。
- 6 工具：`device` / `shell` / `open` / `dial` / `notify_user` / `load_skill`；不设 `intent`、`read_screen`、`launch_app`、`list_apps`、`compose_note`。
- 模型不知道通道；不提供 `via`/坐标参数；结果可带 `channel` 供诊断（D84）。
- 确认只覆盖不可逆/花钱；`dial` 不确认；`shell` 分类 + fail-closed（R-18）。
- 上下文保持 D81 统一预算；只在 D97 ① 前插 ⓪（R-13）；不引入 per-category 预算。
- 图片 K=3、长边 768 为初值；DeepSeek 单图 ≤1024 tokens；按实测校准。
- 进度 UX B：开始一句 + 每工具一行 + 确认/失败/完成 TTS；确认 UX A：眼镜 TTS + 手机弹窗。
- 证据只记计数/id/哈希/状态；不记正文（D117）；设备模拟只用 `edith.phone.a11yprobe`（D95），禁止 `adb shell input tap/text`。
- 只提交，不 push / 不 tag / 不合并；不改写 0.21/0.23/0.24 判词。
- 新增模块/包名遵循 AGENTS.md 的 0.22 规则；`device-control` 不依赖 Android。

## Review Focus

1. **图片 artifact 在发送时已缺失/被清理**：必须降级为文字占位，不崩溃、不向 provider 发空图。
2. **Chat Completions 的 tool 消息带图**：官方不支持（400）；必须只发文本 + 后续 user 图片 workaround。
3. **跨 revision 的 stale ref / 动作后屏幕已变**：必须 `NODE_STALE` + 新观察，不得点到旧节点。
4. **`shell` 分类器被复合/混淆语法绕过**：`sh -c`、`;`、base64、变量 → fail-closed 要求确认。
5. **确认等待期间 STOP/超时/拒绝**：不得执行、不得卡死、不得把等待算进回合预算（D49）。
6. **任务中屏幕熄灭/上锁**：`isInteractive=false` → `DEVICE_SCREEN_OFF`，不得在 keyguard 上盲操作。
