## 3. EDITH 0.26 的实际情况

| 能力 | EDITH 0.26 | 差距 |
|---|---|---|
| 感知输入 | `device.observe` 返回完整 a11y 树文本；`device.screenshot` 可选 | 无默认截图；无 VLM；无自动状态摘要 |
| snapshot 形态 | 原始树行（`#n`/bounds/actions），包含 systemui/home/status bar 等大量节点 | 噪声大；缺少 top package/IME/overlay/关键状态 |
| ref | 有 RefRegistry，模型传 ref；T7 加 bare ref 归一化 | 无 TTL、无页面切换校验、无自动刷新 |
| 操作结果 | `device.act` 后返回 observation/差分 | 没有强制“变更后必须重新观察/验证” |
| 状态 | 没有媒体/前台/亮度等模型可见状态字段 | 模型无法可靠确认“播放在发生/已回桌面” |
| 视觉兜底 | 无 VLM；截图只作为可选工具/验收截图 | 文字树弱的页面（播放器、滑块、搜索建议）没有兜底 |
| 验收 | harness 事后读系统状态；T7 只有终态 | 没有“模型是否感知”验收；早期媒体解析 bug 掩盖播放 |
| 预算 | 原 30s；新加 180s 下限 | 仍无 X-OmniClaw 那种 loop detection/成功监控 |
| 测试 | T7 截图/回答；通用 perception probe 刚加 | 反问答案截图未滚到最新回答，尚未形成矩阵 |

### EDITH 为什么会漏

1. **产品定位不同**：EDITH 是语音助手，工具面后加；`device` 是可选工具，不是运行时感知层。
2. **没有强制闭环**：模型可以 act 后不 observe；没把“上一步结果”作为下一步的强制输入。
3. **无视觉双轨**：屏幕点击任务的关键状态（播放、滑块、搜索建议、广告遮挡）恰是纯文字 a11y 的弱项。
4. **快照不适合模型**：完整树混入系统窗口/状态栏，ref 与目标噪声大；无 top package/IME/overlay 摘要。
5. **没有成功监控**：模型可以按计划声称完成；验收和模型反馈分离，且历史媒体读回有 bug。
6. **验收缺口**：27 行语料只测终态，没有测“模型是否真的感知”；T7 的盲问是第一次直接暴露。
7. **预算/步骤**：旧 30s 截断 T7；新 180s 只解决时间，不解决感知。

## 4. 0.27 建议范围（待业主批准）

### P0 — 感知闭环

1. **紧凑 snapshot**：前台包/Activity、IME/浮层、交互元素 text/id/center/bounds/ref/状态；
   默认过滤 systemui/home/status bar；支持 compact/interactive/tree 三档。
2. **ref 生命周期**：snapshot id/age、页面切换失效、自动刷新、点击前校验；禁止旧 ref 静默点击。
3. **变更后强制观察/验证**：`device.act`/`open` 返回新 snapshot 摘要 + 变更节点 + 前台；
   模型下一步必须基于新快照；成功监控独立于模型自述。
4. **模型可见状态**：`device.status` 至少含前台、媒体播放/曲目、亮度、IME、a11y 可用；
   只在需要时返回，隐私安全。
5. **截图/VLM 兜底**：`device.screenshot(query=...)` 返回分析/grounding；对播放器、滑块、
   搜索建议、广告遮挡优先启用；明确隐私和成本开关。

### P1 — 语料与验收

6. **perception matrix**：所有语料执行“盲问 + observe 后问”，记录：
   - 盲答 vs 实际截图；
   - observe 答 vs 实际截图/系统状态；
   - 模型是否主动观察、是否引用正确状态。
7. **失败原因分类**：`blind_hallucination` / `no_observation` / `wrong_ref` / `stale_ref` /
   `tool_state_unreadable` / `model_no_verify` / `budget`。
8. **T7/T2/T3/T4/T8a/T8c/T6** 全部按新闭环重跑；媒体 `state=3` 等读取规则固定。

### P2 — 工程化

9. 工具结果上下文压缩，保留状态字段而不是整棵树。
10. 回合预算/步骤/循环检测可配置；多步任务不再用单次请求超时代替回合预算。
11. 过程可观测：模型看到的 snapshot id、前台、状态、模型回答、实际截图统一进证据。

## 5. 明确不做什么

- 不直接复制 X-OmniClaw 代码；仅参考架构，复制前做许可证审查。
- 不把“盲问答对”作为感知通过；盲问只用于检测旧上下文污染。
- 不把模型自述“已完成”作为副作用证据；必须读系统状态。
- 不为通过语料而放宽 T7/T8c 判据；T1 已由业主删除，T8c allow 是单独授权证据。
