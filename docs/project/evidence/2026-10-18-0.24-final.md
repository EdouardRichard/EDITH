### 4.7 orphan-wake 修复 `b1d48a2`（2026-10-19）

- **问题（最终复核 Important #1）**：wake 发射路径在 `emitWakeDetected` 之前无条件 `requestPanelOpen(WAKE)`，没有 identity/turn 检查。被插件拒绝的 wake（scene cooldown、激活竞态）可能打开一个无 turn 的空白 480×380 overlay；`ConversationCycle.onPanelShown` 对 null turn 直接返回，不会自动关闭。
- **修复 A（组合层）**：`HostCompositionRoot.emitWake` 现在是生产发射 seam；chime 与 `requestPanelOpen(WAKE)` 都以 `host.currentIdentity() != null` 为门；面板还等待 `SmartAssistantPlugin.canOpenWake()`（插件上下文 active + scene cooldown 允许）。被拒绝的 wake 仍发 `P3_WAKE`/`WakeDetected` 证据，但不请求面板。接受路径与 `emitWakeDetected` 本身保持不变。
- **修复 B（cycle 防御边界）**：`ConversationCycle` 增加独立的 `noTurnCloseExpiry`/`noTurnCloseEpoch`（3 s `NO_TURN_PANEL_CLOSE_MILLIS`，不是 10 s 聆听计时）。`onPanelShown(WAKE)` 无 turn 时 arm；由 `onWake`/`onClose`/`reset` 取消；超时重新检查 turn，避免关闭真实对话；官方 idle 面板保持打开。
- **修复 C（Help 路径）**：插件有 live turn 但 cycle 没有窗口时，`SmartAssistantPlugin.onPanelShown` 跳过 cycle，保留面板。
- **测试**：RED 观察到 no-turn 面板未关闭、无 identity/cooldown 拒绝仍发 `PANEL_OPEN`、Help 面板被 3 s 关闭；GREEN 后新增 8 条用例。全量 **314 suites / 3024 tests / 0F / 0E / 2 skipped**（3016 + 8）。
- **设备核对（K40 `2696813b` + 眼镜 `1901092544027662`；手机 APK 重建并 `install -r` `Success`）**：接受态 wake PASS——手机 `P5_CHIME state=played`、`panel: live mapping - opening without appStart route=WAKE`、`panel: sending PANEL_OPEN route=WAKE`、`P3_WAKE word=EDITH`、`P3_PANEL shown route=WAKE`、`P3_CONV listen ... shown=true`；眼镜 `PANEL_OPEN accepted ... reset=hidden-to-visible`、`OVERLAY added ... size=480x380`、`PANEL_SHOWN route=WAKE sent=true`。
- **`NotMeasured`**：identity/activation-race 与 cooldown 拒绝两个分支未在设备复现（暂停/非活跃时 audio epoch 已 disarm，KWS 不产生 `P3_WAKE`；debug injector 从注入到 `P3_WAKE` 约 8.5 s，无法在 3 s cooldown 内制造两次 KWS 检测）。两分支仅有组合 JVM 覆盖，不声称设备 PASS。
- **残留边界**：admission 检查在 detector 线程、host 事件投递前发生；恰在 scene cooldown 边界的 wake 仍可能被 `openTurn` 接受而 `canOpenWake` 读到“拒绝”。该窗口由既有 3 s `panel_not_shown` 关闭（以及修复 B 的无 turn 3 s 关闭）兜底，不是无界空白面板。

11. **`开始` 瞬间的插件激活竞态**未消除；不声称插件状态 `Active`。
12. **orphan-wake 的 identity-race / cooldown 拒绝分支**：设备不可复现（暂停/非活跃时无 `P3_WAKE`；两次 KWS 检测无法落入 3 s cooldown），只有组合 JVM 覆盖，`NotMeasured`。

**平台残留（不是 `NotMeasured`，也不是通过）**：Settings 下层——Settings 窗口带 `pfl=HIDE_NON_SYSTEM_OVERLAY_WINDOWS`，`com.android.settings` 持有 `android.permission.HIDE_NON_SYSTEM_OVERLAY_WINDOWS`（granted=true），`dumpsys window` 列在 `Hiding System Alert Windows`；独立 `TYPE_APPLICATION_OVERLAY` 探针 `com.sheen.rokid.glasses.overlayspike` 同样被隐藏（`isOnScreen=false`、Surface `shown=false`）。Task 21 ANR reason 为 `Application does not have a focused window`。这是平台保护，不是 EDITH scene bug；业主 2026-10-19 接受残留风险；U-19 的 Settings 分支记 Failed（验收行记 Partial），只对 Settings 实测，不外推所有系统应用。
