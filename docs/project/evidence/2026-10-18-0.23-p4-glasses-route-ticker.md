## 5. 本阶段发现并修复的缺陷

1. **`maxScrollY()` 少算 ScrollView 的 padding**：首版用 `entriesView.height - hintScroll.height`，把上下 padding（10+25 px）算进了可滚动范围之外；钉住时的新条目被定位到“最大偏移”，实际仍在底边之下（截图可见新答句缺失）。改为 `childHeight - (height - paddingTop - paddingBottom)` 后，`max` 从 108 变为 143，新答句出现在屏上（`P4_REVEAL top=143 max=143` 与截图）。**修复后重跑了完整交互测试与截图。**
2. **两条陈旧 instrumentation 断言**（P4 更新 `HintVisibilityTest` 时更正，不是产品回归）：
   - 眼镜端答句按原文显示（`先讲结论。再讲背景`），不再按句号拆行；旧断言期望换行。
   - 旧溢出用例的 182 字符在 16 px 窗口里已不再溢出；改用接近 400 code point 上限的 390 字符合成文本。
   更正后 `OK (9 tests)`。
