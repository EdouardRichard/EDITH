## Root cause fixed

The model was expanding the generic word `文件` into a concrete app name (`文件管理` / `文件管理器`) before calling the
tool. `OpenTool`'s descriptor now tells the model to keep a category word unchanged and let the tool return ambiguity:

> 用户说类别词（如“文件”）时保持原词，不要自行扩成某个具体应用；歧义由工具返回候选。
