## 2. 设备 instrumentation

### 2.1 面板状态断言

```
adb -s 1901092544027662 shell am instrument -w \
  -e class com.sheen.rokid.glasses.GlassesPanelStateTest \
  com.sheen.rokid.glasses.test/androidx.test.runner.AndroidJUnitRunner
```

逐字结果：`OK (4 tests)`。四条分别钉住：

1. WAKE busy → `listening=true / thinking=false / orb=LISTENING`；SAID 后 → `listening=false / thinking=true / orb=THINKING`；SHOW 后 → `orb=ANSWERING` 且正文上屏。
2. PROACTIVE busy 在 **WAKE 视图**下不显示聆听/思考（U8 路由隔离）；PROACTIVE `SHOW` 切到该路由并显示答句；`CLEAR` 后仍 busy → 该路由显示思考。
3. 固定文案：`内容由 AI 生成`、`滑动翻页 / 双击退出`。
4. 用户行 `maxLines=4`、绝对左对齐、颜色 `#B340FF5E`（`GREEN_NORMAL_70`）。
   - **P5 复核更正（D150）**：P3 的 `maxLines=4 + ellipsize=START` 在 AOSP 多行布局上不生效，会保留最旧 4 行；P5 最终构建改为 `TailTextView`，保留**尾部** 4 行并由 `GlassesPanelStateTest` 断言“第六行仍在”。本截图仍是 P3 阶段中间态，U-6 的最终设备断言以 P4/P5 的 `GlassesPanelStateTest` 为准。

> `waitForIdleSync` 未用于这些断言：orb 呼吸动画在聆听/答句态持续运行，界面不会进入“idle”。测试用 700 ms 固定等待代替（见 `waitForLayout` 注释）。
