# 0.24 Settings 下层 overlay 平台保护 — 证据（2026-10-19）

- **范围**：只读/控制证据（另一 agent，2026-10-19），用于解释 0.24 S5 / Task 21 的 Settings 下层异常。**未改产品代码。**
- **设备**：Rokid Glasses `1901092544027662`（Android 12，480×640）。
- **结论**：Settings 对非系统 overlay 启用 `HIDE_NON_SYSTEM_OVERLAY_WINDOWS` 平台保护；EDITH 的 `TYPE_APPLICATION_OVERLAY` 被强制隐藏，**不是 EDITH scene bug**。U-19 的 Settings 分支记 Failed（验收行记 `Partial`）；业主 2026-10-19 接受残留风险。
- **取代关系**：[生产走查](2026-10-19-0.24-s5-production-walkthrough.md) 中的“根因未查明/不猜”与 U-19 `Verified (Device, partial)` 是当时的观察；本文件补充平台证据后取代该判断，U-19 以 `ACCEPTANCE.md` §2.7 的 `Partial` 为准。旧证据文件不改写。

## 2. ANR 链

- Task 21 生产走查中，Settings 下层：EDITH 面板窗口存在（`mViewVisibility=0x0`、alpha 0.8、frame `[0,260][480,640]`）但 `isOnScreen=false`；屏幕截图只有 Settings。
- 注入 BACK 后没有聚焦窗口，ANR reason `Application does not have a focused window`；随后 `ANR in GlassesActivity` → 进程死亡 → `GLASSES_APP_EXIT` → 5 s grace → `Idle`；需重新 appStart 恢复。
- 平台隐藏 overlay 与“注入 BACK 找不到焦点窗口”可解释该链；不是 EDITH 主动隐藏面板或 scene 代码路径。**归因是证据链结论，不是单行日志的直接断言**（单行日志只给 reason）。

## 3. 对照

- **SoundRecorder 下层**：面板 480×380 可见，窗口 `HAS_DRAWN`；见 [生产走查](2026-10-19-0.24-s5-production-walkthrough.md) §4.5 与 [截图](assets/2026-10-19-0.24-s5-rerun/glasses-panel-over-soundrecorder.png)。
- **launcher**：面板隐藏后 launcher 可见；平台读回 scene `translucent=true`、launcher `visibleRequested=true`；见 [截图](assets/2026-10-19-0.24-s5-rerun/glasses-launcher-after-back.png)。

## 4. 业主接受

- 2026-10-19 业主接受“Settings 下层不可覆盖”作为平台残留风险；不要求产品修复，不把 U-19 读成全行 Verified，也不外推为所有系统应用。
- 后续若需要“任意应用可覆盖”，必须先处理平台 `HIDE_NON_SYSTEM_OVERLAY_WINDOWS` 约束；本轮不做。
