## NotMeasured / limitations

- **未测**：真实眼镜 ENTER/BACK 按键 allow/deny、通知 action、锁屏/后台/面板隐藏/通知关闭降级、无可见面 `CONFIRMATION_UNAVAILABLE`、审计/STOP 设备行为、P4_TOOL 延迟矩阵与旧语料。
- **执行通道**：部分后续 turn 的 Shizuku/a11y 执行返回 `ACTION_CHANNEL_UNAVAILABLE`（重启/重装后服务绑定丢失）；“不拦截 0 确认/绕过上限”有策略行证据，但“实际执行成功”不是全量设备证据。
- **不拦截开关**：设备侧用 debug-only `DebugNoInterceptionControl` 调用生产 `storedSettings()`/`saveSmartSettings()`，不是设置页 Compose 开关的点击；二次确认 UI 只有 JVM/编审证据，设备 UI 点击 `NotMeasured`。
- **shell 良性命令**：首次注入因 device shell 引号截断，实际命令不是完整的 `cmd package list packages`；该条设备 `NotMeasured`。B6 JVM 的 13/13 分类测试通过。
- **确认回答**：`P4_CONFIRM channel=voice` 来自 synthetic final transcript（既有 corpus seam），不是眼镜麦克风/真实 ASR；ASR 复读问题仍开放，见 STATUS。
- **UI 无障碍设置**：测试中曾因 force-stop 探针导致其 a11y 绑定丢失，已恢复 `enabled_accessibility_services` 为 EDITH + probe 四项并验证两者 bound；未改变生产命令/设置。
