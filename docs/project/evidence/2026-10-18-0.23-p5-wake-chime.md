## 5. 验收口径与边界（不得读成通过）

- **U-10 设备半边：Verified (Device)**，范围是「真实 KWS 命中 → 生产 wake 路径 → `P5_CHIME state=played/disabled`」；**没有** `P5_SPEECH` 与固定 TTS 短语。注意旧日志的 `played` 是“已请求播放”，最终代码的 `played` 才表示 `startTone` 返回 true；设备可听性仍未测。
- **无身份不响**：最终 `wakeEmit` 在 `host.currentIdentity()==null` 时不调用 chime；旧证据只覆盖有会话时。
- **中文录音**：本轮没有触发 KWS；不得外推中文唤醒率。
- **可听性**（音量/音色/是否像官方）：`NotMeasured`（P6 主观项）。
- **真实声学耦合**（手机扬声器 → 眼镜麦克风）：`NotMeasured`；本证据是 ingress 注入。
- **800 ms 设备侧去抖**：JVM `WakeChimeTest` 钉住；设备上没有构造两次间隔 <800 ms 的唤醒，故设备去抖 `NotMeasured`。
- **ToneGenerator 在真实扬声器上的播放**：`startTone` 被调用且未报 `state=failed`，但「有人听见」是另一类证据，`NotMeasured`。
