## 3. 记忆页（U-4）

### 3.1 合成记忆与还原纪律

debug-only 仪器 `DebugMemoryLogSeed`（`src/debug`，release 无此 receiver）：

```powershell

adb -s 2696813b shell am broadcast -a edith.DEBUG_MEMORY_LOG_SEED -n com.sheen.rokid.phone/.debug.DebugMemoryLogSeed --es mode seed
# 截图后：
adb -s 2696813b shell am broadcast -a edith.DEBUG_MEMORY_LOG_SEED -n com.sheen.rokid.phone/.debug.DebugMemoryLogSeed --es mode restore
```

logcat：

```text

10-18 00:06:52.260  I EdithP3 : P3_P2MEM mode=seed ids=13037b3a-8f7f-4204-afd5-e51317d45a16,d235f78d-d707-4d13-8872-0f3d56b55725 entries=2

10-18 00:07:34.511  I EdithP3 : P3_P2MEM mode=backup present=false bytes=0 sha=e3b0c442...b7852b855
```

复核修复后的仪器加固（最终安装 APK `94E1...`，设备实测）：

```text
10-18 00:22:14.425  I EdithP3 : P3_P2MEM mode=backup refused reason=BACKUP_EXISTS
10-18 00:22:15.245  I EdithP3 : P3_P2MEM mode=restore verified=true entries=0 backupRemoved=true
```

- 业主的真实记忆文档在**执行前就是 absent**（`present=false`），所以 seed 后 restore 的结果是删除 key、`entries=0`，并由 `verified=true` 逐字节确认；执行后再备份仍为 `present=false`。
- **备份文件生命周期**：先在 `00:04:40` 备份（absent marker）→ seed → 截图 → restore 校验 → `00:07:34` 再备份确认 absent。复核加固后，已有的备份**不会被第二次 `backup` 覆盖**（`refused reason=BACKUP_EXISTS`，要覆盖必须显式 `--ez force true`），且 `restore` 校验通过后删除消耗掉的备份（`backupRemoved=true`）。设备最终**没有** `p2-memory-backup.bin`；这消除了“seed 之后再 backup 把合成文档当成原文档、restore 假成功”的数据丢失路径。
- seed 期间文档里**只有**两条合成句子；截图里没有出现任何真实记忆正文。
- 合成句子：短句 13 code point（`P2 证据短记忆：周末散步`）；长句 65 code point（`P2 证据长记忆：这是一条用于验证记忆列表缩略与全屏详情完整全文的合成记录、长度明显超过四十个码点、列表里应当被截断并显示省略号。`）。

### 3.2 列表：缩略规则在设备上的可观察事实

探针轮询读到的长记忆行 accessibility 标签（`A1CLICK_POLL`，原样摘录）：


该标签的正文部分 = `preview(LONG_TEXT)`：**前 40 个 code point + `…`（共 41 个 code point）**；探针用这条完整标签成功点中该行，verdict 原样如下：

```text
P3_A1CLICK_VERDICT outcome=clicked labels=10-18 00:06 | 偏好 | P2 证据长记忆：这是一条用于验证记忆列表缩略与全屏详情完整全文的合成记录、长度… matched=10-18 00:06 | 偏好 | P2 证据长记忆：这是一条用于验证记忆列表缩略与全屏详情完整全文的合成记录、长度… clicked=true polls=1 waitMillis=10000 window=com.sheen.rokid.phone visible=13
```

## 6. 未测 / 不声称

| 项 | 状态 | 原因 |
|---|---|---|
| 技能/记忆详情页人手滚动/滑动手势 | `NotMeasured` | a11yprobe 无通用跨应用滚动意图；D95 禁止 `adb shell input swipe` |
| 详情页文字选中/复制手势 | `NotMeasured` | 探针无文本选择手势；`SelectionContainer` 为代码事实 |
| 40 code point 的**像素级**截断位置 | `NotMeasured` | 屏幕宽度决定 Compose 视觉截断；code point 规则由 JVM 钉住 |
| 超大 `.md`（如 1 MB）在主线程同步读取的卡顿 | `NotMeasured` | 未构造；规格要求不截断，本阶段不加大小上限 |
| 0.21 M2 / AC-13/16 | 保持 0.21 判词 | 0.23 不重测、不改写 |
| 眼镜端 / 侧键 / 佩戴可读性 / 功耗 | `NotMeasured` | 不属于 P2，P3–P6 处理 |

## 7. 结论

- **U-3**：`Verified (JVM + Device)` —— JVM `SkillDirectoryViewTest` 10/10（含非法名不触达 `readFile`、空/未授权可区分、长文本不丢）；设备截图显示完整全文、空文件文案、**列表级与详情级不可读文案**（`skills-unreadable.png` / `skill-unreadable-detail.png`）。
- **U-4**：`Verified (JVM + Device)` —— JVM `MemoryLogViewTest` 16/16（40 code point 边界、代理对、列表行、存储不变）；设备截图显示长句缩略（40 + `…` 的数据级标签）、短句完整、点击后详情全文；`P3_P2MEM mode=restore verified=true`；复核加固后另有 `mode=backup refused reason=BACKUP_EXISTS` 与 `backupRemoved=true`（仪器不会用合成文档覆盖唯一还原路径）。
- **边界**：§6 的 `NotMeasured` 逐条保留，不读成通过。
